omp package repos

Fork: PfisterFactor/oh-my-pi — updated on every push to main.

Fedora / RHEL (dnf)

sudo dnf config-manager addrepo --from-repofile=https://pfisterfactor.github.io/oh-my-pi/omp.repo
sudo dnf install omp

Update with sudo dnf upgrade omp.

Debian / Ubuntu (apt)

sudo curl -fsSL https://pfisterfactor.github.io/oh-my-pi/omp.list -o /etc/apt/sources.list.d/omp.list
sudo apt-get update
sudo apt-get install omp

Update with sudo apt-get update && sudo apt-get upgrade omp. Modern apt can also use the deb822 form: omp.sources → /etc/apt/sources.list.d/omp.sources.
